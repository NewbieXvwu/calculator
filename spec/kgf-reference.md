## 1. 显示格式规格（截图实测，照抄原版）

| 项 | 原版规格 |
|---|---|
| 定义域 | `x ∈ ℝ` / `x ≠ 0` / `x ≥ 0` / `x ≠ πn₁ + π/2, ∀n₁ ∈ ℤ` |
| 值域 | `y ∈ ℝ` / `y ∈ ℝ \ {0}` / `y ∈ (0,100]` / `y ∈ [0,∞)` / `y ∈ (−∞,−2] ∪ [2,∞)` / `y ∈ [−1,1]` / `y ∈ {5}` |
| 空截距 | `∅` |
| 空极值 / 拐点 / 渐近线 | 完整中文句子 + 句号（如「此函数没有任何极小值点。」） |
| 渐近线 | 方程形式 `x = 0` / `y = x + 1` |
| 极值 / 拐点 | 坐标对 `(0,100)` / `(√6/3, −4√6/9)` |
| 多零点分隔 | `x = −√2 or x = 0 or x = √2`（中文界面里也是英文 "or"） |
| 多条渐近线 | 分行显示（`\|x\|` 的 `y = x` / `y = −x`） |
| 周期 | 符号形式 `2π` / `π` |
| too complex | 底部独立段落 +「这些功能过于复杂，计算器无法计算:」+ 逗号分隔字段名 |
| 通解 | 零点用 `n₁ ∈ ℤ`（无 ∀）；定义域用 `∀n₁ ∈ ℤ`（有 ∀） |
| 不化简 | 原版保留 `sin(π/2)` 不化简为 `1`；我们也不追求深度化简 |

注意**定义域与值域记号不对称**：同样挖掉一个点，定义域写 `x ≠ 0`，值域写 `y ∈ ℝ \ {0}`。

**字段显示顺序**（XAML 定，非枚举顺序）：

```
定义域 → 值域 → X轴截距 → Y轴截距 → 极小值 → 极大值 → 拐点
→ 垂直渐近线 → 水平渐近线 → 斜渐近线 → 奇偶性 → 单调性 → 周期
```

**单调性区间顺序**：原版无规律（`1/x`、`x³-2x`、`|x|` 右到左；`x+1/x` 给出
`(0,1)→(1,∞)→(-∞,-1)→(-1,0)`），判定为引擎内部发现顺序的泄漏，无语义。
→ **我方固定从左到右**（M1 第 (4) 类偏差，故意）。

## 2. 原版三处 UI bug（我方必须修，M1 第 (4) 类）

| 函数 | 原版现象 | 机制 | 我方做法 |
|---|---|---|---|
| `tan(x)` | 垂直渐近线栏显示「没有」，同时又列进 too complex | 字段标 TooComplexFeatures 后未抑制默认 `KGF*None` 文案，两个信息源缺互斥 | 字段标 too complex 时**不显示** None 文案 |
| `sin(1/x)` | 拐点栏显示「没有转折点」，同时又列进 too complex | 同上 | 同上 |
| `sin(x)+sin(πx)` | X 截距栏说「没有」，但 x=0 处确为 0（Y 截距栏自己写了 `y=0`） | 原版引擎 bug | 我方给出两族有理化通解（数学正确） |

## 3. 14 函数逐 case 对照

图例：✅ 与原版语义一致；🟡 格式差（语义等价，单独跟踪）；⬜ 缺失（我方 too complex
降级，原版有值）；✅+ 强于原版（M1 第 (4) 类记录）；「未存档」= 原版该格子当时未记录。

### 3.1 `x^2-2`（tests: 01_poly2）
原版（实测）：零点 `x = −√2 or x = √2`、极小值 `(0,−2)`。其余格未存档。
我方：定义域 ℝ；值域 `[-2, +∞)`；零点 `-sqrt(2), sqrt(2)` 🟡（原版 `√2` 记号）；
极小 `(0,-2)` ✅；单调性左到右 2 段；无 too complex。

### 3.2 `1/x`（02_recip）
原版（实测）：值域 `y ∈ ℝ \ {0}`；VA `x = 0`；HA `y = 0`；单调性右到左。
我方：值域 `ℝ \ {0}` ✅（🟡 无 `y ∈` 前缀）；VA/HA 同 ✅；单调性左到右（故意偏差）。

### 3.3 `sin(x)`（03_sin）
原版（实测）：极值/单调性给出主区间族。
我方：定义域 ℝ ✅（经「Auto assume 区间=一个完整周期且无排除点 ⇒ ℝ」推理，见 §4.2）；
值域 `[-1, 1]` ✅；零点通解 `n·π` ✅（🟡 记号 `πn₁`）；周期 `2·π` 🟡（原版 `2π`）；
VA 确定无 ✅；极值/拐点/单调性 too complex ⬜（通解族属第二阶段，见 TODO S3「暂不做」）。

### 3.4 `tan(x)`（04_tan）
原版（实测）：定义域 `x ≠ πn₁ + π/2, ∀n₁ ∈ ℤ`；VA 栏出 UI bug（§2）。
我方：定义域/值域/VA/HA/极值/拐点/单调性全部 too complex ⬜——giac `Auto assume
x∈[0,2π]` 截断（R3），宁缺勿错；零点 `n·π`、周期 `π`、奇函数 ✅。

### 3.5 `x^3-2x`（05_poly3）
原版（实测）：极值 `(√6/3, −4√6/9)` 等、拐点 (0,0)、单调性右到左 3 段。
我方：全字段有值 ✅；极值 x 记 `1/3·sqrt(6)` 🟡（同值异形）；单调性左到右。

### 3.6 `abs(x)`（06_abs）
原版（实测）：斜渐近线两条 `y = x` / `y = −x` 分行；极小值 (0,0)。
我方：OA `y = -x`,`y = x` ✅；极小 (0,0) ✅（不可导点单独判别）；拐点确定无
（二阶导恒 0）✅；单调性 2 段 ✅。

### 3.7 `sqrt(x)`（07_sqrt）
原版（实测）：定义域 `x ≥ 0`；极小值 (0,0)。
我方：定义域 `x>=0` 🟡（记号）；值域 `[0, +∞)` ✅；极小 (0,0)（闭端点判别）✅。

### 3.8 `x+1/x`（08_x_plus_recip）
原版（实测）：值域 `y ∈ (−∞,−2] ∪ [2,∞)`；极值 (1,2)/(−1,−2)；OA `y = x`；VA `x = 0`。
我方：全部一致 ✅；值域由驻点值∪端点极限构造（R2）。

### 3.9 `(x^2-1)/(x-1)`（09_hole）
原版（实测）：值域 `y ∈ ℝ \ {2}`（可去奇点的极限值从值域挖掉）；VA 无；OA `y = x + 1`。
我方：全部一致 ✅；挖点极限 2 经单侧极限构造进值域（R2 第三例）；拐点确定无
（二阶导恒 0）✅。

### 3.10 `1/(x^2+0.01)`（10_bump）
原版（实测）：值域 `y ∈ (0,100]`；极大 (0,100)；HA `y = 0`。
我方：一致 ✅；极大 (0,100) 依赖 sign 数值解析（R5，浮点系数 `-1.0`）；
拐点两个数值点 🟡（原版为 `±√3/30` 类精确形；同值）。

### 3.11 `sin(1/x)`（11_sin_recip）
原版（实测）：值域/周期 too complex；拐点栏出 UI bug（§2）。
我方：值域 `[-1, 1]` ✅+（有界振荡路径：顶层 sin + `solve(f=±1)` 非空）；
非周期 ✅+；零点通解 `1/(n·π)` ✅+；VA 确定无（挖点单侧极限有界）✅；
极值/拐点/单调性 too complex ⬜（bisection 数值洪水，R4 拒收）。

### 3.12 `sin(x)+sin(pi*x)`（12_sin_mix）
原版（实测）：周期 too complex；X 截距出引擎 bug 说「没有」（§2）；
HA 曾泄漏 `y = bounded_function(17)`（这是原版没有的错误，是我方 S3 前的 bug，已修 R1）。
我方：非周期 ✅+（`period()` 返回 `+infinity`）；X 截距两族有理化通解 ✅+；
定义域 ℝ、VA/HA 确定无 ✅；值域/极值/拐点/单调性 too complex ⬜。

### 3.13 `5`（13_const）
原版（实测）：值域 `y ∈ {5}`；偶函数；周期字段**不显示**。
我方：常函数短路径：值域 `{5}`、单调性「恒定」、周期不显示（R6：`period()==0`
= 任意周期，非「周期为 0」）✅。

### 3.14 `e^x`（14_exp）
原版格子未存档。
我方：定义域 ℝ；值域 `(0, +∞)`（端点极限构造）；HA `y = 0`；单调性 1 段递增；
无 too complex。数学上自洽（经 giac 验证）。

## 4. 我方实现要点备忘（与 TODO §S3 的 R1–R6 对应）

### 4.1 六类根因修复
- **R1** `bounded_function(k)` = 极限有界但不存在 = **确定无 HA**（不是 too complex）；
  显示白名单外的任何 giac 记号一律不显示。
- **R2** 值域从「驻点值 ∪ 端点极限 ∪ VA 单侧极限 ∪ 挖点极限」构造；构造不出完整
  结构 → too complex，绝不给包含取不到值的区间。
- **R3** 检测 stderr `Auto assume` 警告（GiacBridge `evaluate:warningsOut:`）→ 相关
  字段 too complex；唯一例外见 §4.2。
- **R4** stderr bisection 提示 / 解数 >20 → 整字段 too complex。
- **R5** `sign()` 结果一律数值解析（`Double(s)`），不做字符串精确匹配。
- **R6** `period()==0` → 不显示周期；`+infinity` → 非周期。

### 4.2 Auto assume 下唯一可信的推理
实测（`.scratch` probe，2026-07-31）：giac 周期函数的 Auto assume 区间**恰为一个完整
周期**（`tan(x/3)` → `[0,3π]`）。故 `domain()` 在该警告下返回 `x`（无排除点）时，
可推出全 ℝ 无排除点 → 定义域 ℝ 可信。返回任何带排除点的结果仍不可信（tan 案例）。

### 4.3 VA 判定
`solve(denom(normal(f))=0)`（天然剔除可去奇点）+ 对定义域排除点/开有限边界逐点
单侧极限验证（`±infinity` → VA；`bounded_function`/有限值 → 非 VA；未知记号 →
整字段 too complex）。定义域不可信时 VA 必 too complex（奇点集合未知）。

### 4.4 性能
查询预算 100 条 / 总超时 1.8s，超限剩余字段 too complex。实测 14 case 全部
≤0.5s（回归测试断言 ≤2s，S3 验收线）。

### 4.5 已知 🟡 格式差清单（语义等价，待 UI 层统一渲染时消化）
1. `sqrt(2)` vs `√2`、`1/3·sqrt(6)` vs `√6/3`（根式记号）
2. `2·π` vs `2π`（乘点）
3. 定义域 `x<>0`/`x>=0` vs `x ≠ 0`/`x ≥ 0`（比较记号）
4. 值域无 `y ∈` 前缀（原版有）
5. 通解变量 `n` vs `n₁`，且无 `n₁ ∈ ℤ` 后缀
6. `1/(x^2+0.01)` 拐点为数值形而非精确形
7. 零点以列表返回，UI 层需按原版以 ` or ` 连接
